RepoCoach · FE INTERVIEW LAB
Windows 桌面版 1.0.0

安装：双击 RepoCoach-Setup-1.0.0.exe，按向导完成安装。
桌面和开始菜单将生成名称为 RepoCoach 的快捷方式。
默认安装位置：当前用户的 AppData\Local\Programs\RepoCoach。
无需管理员权限。支持 Windows 10 / 11。

打开：双击 RepoCoach 图标。优先使用 Edge 或 Chrome 的独立应用窗口；
未找到时使用系统默认浏览器。需保持联网，访问现有线上服务：
https://repocoach-web.onrender.com/
首次访问 Render 免费实例可能需要等待几十秒唤醒。

此安装包是线上项目的桌面入口，不包含本地服务器和数据库。
安装时无需 Node.js、Docker、PostgreSQL 或个人模型 API Key。
账号、训练历史及报告保存在现有线上服务。
本机需有 Microsoft Edge、Chrome 或可用的默认浏览器，
以及 Windows 10/11 自带的 .NET Framework 4.x。

卸载：Windows 设置 → 应用 → RepoCoach → 卸载，
或使用开始菜单中的“卸载 RepoCoach”。
卸载仅移除程序和快捷方式，不会删除云端账号或训练记录。

源码、更新与下载：https://github.com/X-wj28/repocoach-ai
