# 训练参考答案

训练原先只保存四项评分、优点与改进建议，没有生成或展示可供对照学习的参考回答。

现在提交回答后，评分模型会在同一次请求中生成 `referenceAnswer`：纯文本参考回答与源码证据 ID。回答直接回应当前题目，说明结论、代码调用/数据流、技术取舍和失败边界及验证。证据不足时，要求说明已知事实和待核对部分。

服务端拒绝缺失或空白参考回答、超过 6000 字符的正文、伪造或重复引用；非证据不足的回答至少需要一个实际证据 ID。格式不合格沿用评分阶段失败与重试流程，复用已保存的代码依据。评分提示版本更新为 `rubric-grader-v3`，升级前创建的 v2 待完成任务仍可继续。

参考答案保存在已有的评价 JSON 中，无需数据库迁移。训练反馈、历史逐题复盘和 Markdown 导出均可查看；页面上的源码引用可打开本题保存的代码。答题前不展示参考答案。旧记录明确提示当时未保存，演示模式明确提示未生成。

验证使用固定模型输出与隔离 API/数据库，不调用真实模型，不代表生成内容的语义正确性已经过人工评审。

- `npm run test:api`：评分输出与引用校验、证据不足、版本兼容、持久化读取及旧记录兼容。
- `npm run test:web`、`npm run lint`、`npm run build --workspace apps/web`：前端回归、静态检查和生产构建。
- `npm run test:browser`：提交前隐藏、完成后展示、源码跳转、390px 手机布局、恢复评分后的参考答案、复盘读取与导出、旧记录与演示提示。
- `TEST_DATABASE_URL` 指向专用测试数据库时，`npm run test:integration` 和 `npm run test:e2e` 验证真实 PostgreSQL 事务与 HTTP 重试后的参考答案保存和读取。
