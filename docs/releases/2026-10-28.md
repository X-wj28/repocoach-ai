# 2026-10-28 可视化训练工作台发布

发布前检查已完成，正在准备 GitHub CI 与 Render 部署。此页在部署后补充实际提交、CI、线上版本与验证结果；当前不能作为已经上线的证明。

## 本轮变化

此前页面以题目和评价为中心。本轮提供完整的“回答 → 查看执行 → 核对源码 → 逐题复盘 → 本次小结 → 下一次练习”工作区，继续使用 Next.js、NestJS、PostgreSQL、Prisma 和 DeepSeek。

| 范围 | 新行为与实际作用 |
| --- | --- |
| 训练工作台 | 回答区更宽，五阶段进度读取服务端状态；工具事件、评分引用和保存的源码在侧栏联动 |
| 回答操作 | 可展开四段提纲；Ctrl/⌘ + Enter 提交；复制降级、清空确认和本机草稿降低误操作与刷新丢失 |
| 恢复与隔离 | 恢复失败可重试；启动和提交失败保留原内容；切换项目或账号使迟到请求失效；最新训练完成后不恢复更早的遗留训练 |
| 复盘 | 按题切换原始回答、评分、源码和执行记录；Markdown 导出整场内容；嵌套弹窗保持焦点和滚动 |
| 能力报告 | 可选择维度和最近训练点；真实零分与没有评分分开，缺失值不连线；练习建议直达来源题 |
| 训练计划 | 区分加载、失败、重试、空记录与清除反馈；清除时保护当前回答，旧读取不能恢复已清观察 |
| 本次小结 | 当次统计与累计报告分开；低分建议需要保存引用，证据缺口另列；可继续复盘、导出或开始下一次训练 |
| 工程验收 | 新增可重复的生产前端 Chromium 验收与 CI 失败产物，覆盖桌面、390px 手机、异步竞争与恢复 |

## 发布前验证

- API 单元测试 69 项，前端测试 19 项通过。
- 六组生产界面浏览器验收通过：训练、复盘、报告、会话恢复、训练体验和本次小结；未捕获浏览器异常为 0。
- lint、TypeScript、生产构建与差异格式检查通过。
- 20 条合成 Rubric 样例通过离线结构校验，默认无模型调用，人工复核仍为 0。
- 真实 PostgreSQL 11 个场景与 NestJS HTTP 8 个场景的本地验证记录见[本地验收](../demo-readiness.md)；此次 CI 会再次执行。

## 发布方式与边界

先在发布分支执行 GitHub CI，通过后将相同提交快进到 main；临时停用自动部署以依次更新 API 和 Web，两者 Live 后核对健康检查和 HTML 版本，再恢复原自动部署设置。保留现有免费服务、Neon 数据库和服务端密钥，不创建付费资源，本轮没有新增数据库迁移。

小结、图表和提纲用于训练组织与复盘，不能据此声称学习效果、面试通过率或评分准确率提高。固定数据浏览器验收与真实线上验证分别记录。
