## 可复现验证

```powershell
npm run db:generate
npm run test:api
npm run test:web
npm run lint
npm run build
npm run eval:rubric

# 仅设置专用测试数据库；测试会创建、迁移并删除随机测试 schema。
$env:TEST_DATABASE_URL = 'postgresql://repocoach:repocoach@localhost:5432/repocoach?schema=public'
npm run test:integration
npm run test:e2e

# 检查当前 DATABASE_URL 的连通性、应用字段和迁移状态，不输出密码。
npm run db:check

# 可选：使用配置的真实模型，产生少量 API 费用；只发送合成样例。
npm run agent:smoke
npm run eval:rubric:live
```

评分为独立的无工具JSON调用，服务端严格校验分项和引用；已配置模型的故障进入失败阶段。没有配置模型时才使用无分演示。临时账号和浏览器脚本存于被忽略的`data`目录，其中有本地登录态，不能整体复制或提交；可提交的评测结果仅包含合成代码与回答。
